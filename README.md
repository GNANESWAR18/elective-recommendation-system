# Elective Recommendation System

## Overview
An end-to-end machine learning project that recommends university electives to students based on their academic scores and personal interests. The system features a **React + FastAPI full-stack application** as the primary interface, with the original Streamlit app preserved as a standalone ML demo.

## Problem Statement
Choosing the right elective can be difficult for students. Academic strengths (programming, mathematics, databases, AI, ML, web, data science) together with declared interests (AI, web, data, programming, cloud, security) contain useful signals for a suitable elective. This project learns those signals from data and provides a ranked recommendation with confidence.

## Solution
A supervised classification model maps a 13-dimensional student profile to one of six electives:
- Artificial Intelligence
- Cloud Computing
- Cyber Security
- Data Science
- Machine Learning
- Web Development

### Machine Learning Pipeline
1. **Synthetic data generation** with realistic, noisy relationships between scores/interests and electives.
2. **Exploratory Data Analysis** (distributions, correlations).
3. **Model training & comparison** (Logistic Regression, Random Forest, Gradient Boosting) with stratified train/test split.
4. **Best model selection** (macro-F1) and persistence via `joblib`.
5. **REST API** (FastAPI) returning top-1 elective, confidence, and top-3 with probabilities.
6. **React frontend** for interactive use (primary interface).
7. **Streamlit web app** as a standalone ML demo (secondary option).

## Features
- Student profile input (7 academic scores + 6 interest ratings)
- Academic performance analysis
- Interest-based recommendation
- Multiple ML models compared
- Top-3 elective recommendations with probabilities
- Interactive probability bar chart (Recharts)
- Clean, printable student profile summary
- Reproducible synthetic dataset generator
- EDA visualizations saved as PNG
- Responsive design (mobile to desktop)
- Accessible form controls
- Loading and error states

## Dataset
The dataset (`data/elective_recommendation_students.csv`) is **synthetic**, generated by `src/generate_dataset.py` with a fixed random seed (`42`). It contains **1,000 student records** and **15 columns** (13 features + `student_id` + target `preferred_elective`). **No real student data were used.**

## Machine Learning

| Step | Detail |
|------|--------|
| **Preprocessing** | `StandardScaler` for Logistic Regression; tree models use raw features. Target encoded with `LabelEncoder`. |
| **Train / Test split** | 80% / 20% stratified, `random_state=42`. |
| **Models tested** | Logistic Regression, Random Forest (300 trees), Gradient Boosting. |
| **Evaluation metrics** | Accuracy, Macro-Precision, Macro-Recall, Macro-F1. |
| **Model selection** | Highest macro-F1 on test set. |
| **Best model** | **Logistic Regression** (Accuracy ≈ 91%, Macro-F1 ≈ 0.9071). |
| **Feature insight** | Coefficients per class show strong positive weights for relevant scores/interests (e.g., `interest_security` → Cyber Security). |

### Model Comparison (test set)

| Model | Accuracy | Precision | Recall | F1 |
|-------|----------|-----------|--------|----|
| Logistic Regression | 0.9100 | 0.9176 | 0.9011 | 0.9071 |
| Random Forest | 0.7050 | 0.7046 | 0.6645 | 0.6767 |
| Gradient Boosting | 0.8050 | 0.7970 | 0.7908 | 0.7924 |

> **Note:** These results are measured on the synthetic dataset generated by the project. Do not misrepresent this as real university/student data.

## Local Setup

### Prerequisites
- Python 3.11+
- Node.js 18+
- Git

### Backend Setup (FastAPI)
```powershell
cd backend
python -m venv .venv
.venv\Scripts\activate          # Windows
# source .venv/bin/activate     # Linux/Mac
pip install -r requirements.txt

# Run development server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
API available at: http://127.0.0.1:8000
Swagger docs at: http://127.0.0.1:8000/docs

### Frontend Setup (React + Vite)
```powershell
cd frontend
npm install

# Development server
npm run dev
```
App available at: http://localhost:5173

The frontend proxies API calls to `http://127.0.0.1:8000` via Vite's dev proxy. For production, set `VITE_API_URL` in `.env`.

### Streamlit Setup (Standalone Demo)
```powershell
# From project root
python -m venv .venv311
.venv311\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```
App available at: http://localhost:8501

### POST /api/predict
Get elective recommendation for a student profile.

**Request:**
```json
{
  "programming_score": 70,
  "mathematics_score": 70,
  "database_score": 65,
  "ai_score": 60,
  "ml_score": 60,
  "web_score": 65,
  "data_science_score": 60,
  "interest_ai": 3,
  "interest_web": 3,
  "interest_data": 3,
  "interest_programming": 3,
  "interest_cloud": 3,
  "interest_security": 3
}
```

**Validation:**
- Academic scores: integer 0–100
- Interest values: integer 1–5
- No extra fields allowed

**Response:**
```json
{
  "recommended_elective": "Web Development",
  "confidence": 51.3,
  "top_recommendations": [
    {"elective": "Web Development", "probability": 51.3},
    {"elective": "Machine Learning", "probability": 22.8},
    {"elective": "Cyber Security", "probability": 10.4}
  ]
}
```

## Deployment

### Backend (Render / Railway / Fly.io / any Python host)
1. Set build command: `pip install -r backend/requirements.txt`
2. Set start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
3. Ensure `models/` directory is included in deployment (contains `.pkl` files)
4. Set `CORS_ORIGINS` environment variable for production frontend URL

### Frontend (Vercel / Netlify / Cloudflare Pages)
1. Set build command: `cd frontend && npm run build`
2. Set output directory: `frontend/dist`
3. Set environment variable: `VITE_API_URL=https://your-backend-url.com`
4. Deploy

### Docker (Optional)
Create `Dockerfile.backend` and `Dockerfile.frontend` for containerized deployment.

## Environment Variables

### Backend (`backend/.env`)
| Variable | Description | Default |
|----------|-------------|---------|
| `CORS_ORIGINS` | Comma-separated allowed origins | `http://localhost:5173,http://127.0.0.1:5173` |

### Frontend (`frontend/.env`)
| Variable | Description | Default |
|----------|-------------|---------|
| `VITE_API_URL` | Backend API base URL | `http://127.0.0.1:8000` |

Copy `.env.example` to `.env` and modify as needed. **Never commit real secrets.**

## Limitations
- Dataset is synthetic; relationships are handcrafted and may not reflect real university data.
- Recommendations are only as good as the training data and the chosen features.
- Not a substitute for professional academic advising.
- Model performance (≈91% accuracy) is measured on the same synthetic distribution; real-world deployment would need genuine data and further validation.
- scikit-learn version mismatch warning when loading model (trained with 1.9.1, works with 1.9.1+).
